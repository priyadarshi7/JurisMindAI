# JurisMindAI

**Agentic Legal Research & Intelligence Platform** for Indian law — hybrid
retrieval (BM25 + vector), an evidence chain from retrieved passage to
individually validated citation, and a Neo4j citation graph, served through
a FastAPI/Celery backend and a React/TypeScript research workspace.

The project lives in [`tradegraph/`](tradegraph/) — see
**[tradegraph/README.md](tradegraph/README.md)** for setup, architecture,
and everything else.
